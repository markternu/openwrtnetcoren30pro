# Netcore N30 Pro — USB 供电修复固件交付说明

> 本目录交付针对 **磊科 Netcore N30 Pro(Netis NX30V2 / POWER30AX / GW3001 / GLC W7 同硬件)**
> MT7981B (Filogic 820) 路由器,修复:
> 1. USB 口物理无 5V 供电(VBUS 不输出)→ 插入中兴 F50 / U 盘等设备完全不启动;
> 2. 识别中兴 F50 等 USB 网络共享设备所需的驱动缺失。

---

## 一、问题根因(已核实)

固件(含 SamZong 编译的 V2 版本)在设备树 DTS 中仅做了:

```dts
&usb_phy {
	status = "okay";
};

&xhci {
	status = "okay";          /* 没有 vbus-supply! */
};
```

而 `xhci-mtk` 驱动初始化时会向设备树查找 **`vbus`(以及 `vusb33`)供电 regulator**。
设备树里没有定义任何 regulator → 内核退化为 dummy(空占位),日志可见:

```
xhci-mtk 11200000.usb: supply bus not found, using dummy regulator
```

dummy regulator 不会真正把 GPIO/电源开关拉高,因此 **USB 口 5V VBUS 物理上没有输出**,
表现为:插入任何设备(中兴 F50、U 盘)指示灯都不亮、内核完全枚举不到设备。

## 二、修复方案(与社区已验证方案一致)

N30 Pro / NX30V2 这块主板(与 netis NX32U、RAX3000M 同 ODM 参考设计)的
**USB 5V VBUS 由 GPIO23(高有效)控制**。修复只需在 DTS 中:

1. 增加一个 `regulator-fixed` 节点,把 GPIO23 定义为 5V VBUS 电源;
2. 把它挂到 xHCI 节点的 `vbus-supply` 上(驱动 probe 时使能,VBUS 上电);
3. 保留 `regulator-boot-on`,保证开机早期 GPIO 即被拉高,不依赖驱动加载顺序。

```dts
	usb_vbus: regulator-usb-vbus {
		compatible = "regulator-fixed";
		regulator-name = "usb-vbus";
		regulator-min-microvolt = <5000000>;
		regulator-max-microvolt = <5000000>;
		gpios = <&pio 23 GPIO_ACTIVE_HIGH>;
		enable-active-high;
		regulator-boot-on;
	};
...
&xhci {
	vbus-supply = <&usb_vbus>;
	status = "okay";
};
```

依据:
- 同 ODM 的 **netis NX32U** 官方 DTS(`mt7981b-netis-nx32u.dts`)用完全相同的 `pio 23` 做 `usb-vbus`;
- 社区作者 **bfdeh/54iter** 的 N30 Pro 可用固件(`mt7981b-netcore-n30pro.dts`)用 GPIO23 供电,实测
  USB 网络共享(手机/中兴F50)成功;
- 修复后 dmesg 中 `supply bus not found, using dummy regulator` 将消失。

> 说明:若个别主板批次 VBUS 为常供电硬件,GPIO23 拉高亦无副作用,本补丁兼容两种情况。

## 三、中兴 F50 识别所需驱动(已内置固件)

F50 通过 USB 共享网络时,内核按 RNDIS / CDC-ECM 类 USB 网卡枚举(接口名如 `usb0` / `eth2`)。
固件已预置以下 kmod(无需再 opkg):

| 包 | 作用 |
|---|---|
| `kmod-usb3` | USB3.0 xHCI 主控制器(含 mtk 平台支持) |
| `kmod-usb-net` | usbnet 通用框架 |
| `kmod-usb-net-cdc-ether` | CDC-ECM 以太网(中兴F50/多数手机) |
| `kmod-usb-net-rndis` | RNDIS 网络共享(中兴F50/Windows Phone) |
| `kmod-usb-net-cdc-ncm` | CDC-NCM 网络共享 |
| `kmod-usb-acm` | CDC-ACM(部分 4G/5G 棒/串口设备) |
| `kmod-usb-storage` / `kmod-usb-storage-uas` | U 盘 / USB 移动硬盘 |
| `block-mount` | 挂载块设备辅助 |

## 四、代码改动清单(相对 SamZong233/immortalwrt commit 3c71dfc2b6,即 V2 固件源码)

| 文件 | 改动 |
|---|---|
| `target/linux/mediatek/dts/mt7981b-netcore-n30pro.dts` | 新增 `usb_vbus` regulator(GPIO23)并给 `&xhci` 挂 `vbus-supply`;`&usb_phy`/5 网口布局保持不变 |

本目录 `patches/` 内含修改后文件的完整副本,可直接覆盖。
